# Морской бой (Battleship Game)

Классическая игра "Морской бой", реализованная с использованием PyQt5.

## Правила игры

1. Игровое поле представляет собой сетку 10x10 клеток
2. Каждый игрок размещает свои корабли:
   - 1 корабль размером 4 клетки
   - 2 корабля размером 3 клетки
   - 3 корабля размером 2 клетки
   - 4 корабля размером 1 клетка
3. Корабли не могут соприкасаться друг с другом (даже углами)
4. Игроки по очереди делают выстрелы, называя координаты
5. При попадании в корабль противника, игрок получает право на дополнительный выстрел
6. Побеждает тот, кто первым уничтожит все корабли противника

## Управление

- Используйте мышь для размещения кораблей и совершения выстрелов
- Выберите ориентацию корабля (горизонтально/вертикально) перед размещением
- Кликните на клетку противника для совершения выстрела
